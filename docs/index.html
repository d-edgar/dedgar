ChatHarbor

A Mac app for comparing answers from different AI models and brainstorming with them in one place.

See ChatHarbor features Read the code on GitHub Get the Mac download

Requires macOS 14 or later. Connect an AI service with an API key (an access code from that provider), or use models downloaded to your Mac with Ollama or LM Studio. Cloud providers may charge for usage.

  • Compare answers

    Ask 2–4 AI models the same question. Compare their answers, response times, and estimated costs side by side.

  • Test an idea

    Give each AI a role, narrow down the options, and ask them to challenge assumptions before you decide.

  • Keep the decision

    Save a summary of your decision and why you made it. Export it as a PDF or Markdown text file, then return later to record what happened.

  • Run it on your Mac

    Use Ollama or LM Studio to run AI models on your own Mac, including every participant in a brainstorm. This option needs no cloud API key.

  • What’s coming next?

    Upcoming updates add separate Personal and Work spaces, plus a skippable introductory tour. These features are not included in the published download yet.

About me

IT support and Mac management

I’ve worked in IT since 2006, when I began my degree at Old Dominion University. What started as a computer hobby became a career helping people use technology and keeping their computers running.

I’m the Manager of Technical Support Services at Christopher Newport University. I lead support teams and manage Apple devices with Jamf Pro, software that helps IT teams set up and maintain Macs.

Outside of work, I run, build apps, and share what I’ve learned with the Mac admin community at conferences like ACCS.
